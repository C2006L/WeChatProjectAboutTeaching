# 产品需求概述（V1 打样对齐版）

> 伴芽：面向乡村支教教师的生命教育与安全成长课程赋能平台。

## 1. 产品定位
- **核心使命**：为乡村支教教师提供系统化的生命教育与安全成长课程资源、培训与教学工具，帮助教师更专业地陪伴孩子成长。
- **双端说明**：
  - 小程序端（伴芽）：供支教教师使用，覆盖课程获取、培训学习、备课助手、敏感问题应答、个人中心。
  - Web 管理端（伴芽）：供平台运营/管理员使用，覆盖数据看板、课程/培训/案例/教师/队伍管理、审核与资源库。

## 2. 角色与权限
- **支教教师（小程序端）**：
  - 浏览生命教育课程包
  - 学习培训课程（必修 + 选修）
  - 使用教师工具箱（敏感问题应答、备课助手、家校沟通、课堂活动库）
  - 查看个人学习记录与收藏
- **平台管理员（Web 管理端）**：
  - 查看平台数据看板
  - 管理课程、培训、案例、资源
  - 管理教师、支教队伍、种子教师
  - 处理审核、问答与反馈

## 3. 核心流程

### 小程序端
```
登录/首页
  ├─ 找课程 → 课程列表 → 课程详情 → 开始备课/查看材料
  ├─ 学培训 → 培训首页 → 视频播放 → 完成学习
  ├─ 备课工具 → 教师工具箱 → 敏感问题应答 / 备课助手
  └─ 我的 → 学习记录 / 收藏 / 下载 / 设置
```

### Web 管理端
```
登录
  └─ 数据看板
       ├─ 课程管理（V1 完整实现）
       ├─ 培训管理（V1 占位）
       ├─ 案例管理（V1 占位）
       ├─ 种子教师（V1 占位）
       ├─ 支教队伍（V1 占位）
       ├─ 教师管理（V1 占位）
       ├─ 问答与反馈（V1 占位）
       ├─ 审核中心（V1 占位）
       ├─ 资源库（V1 占位）
       └─ 系统设置（V1 占位）
```

## 4. 核心模块清单

### 小程序端
- [ ] 首页模块：问候语、支教阶段 Hero 卡、四宫格快速入口、今日推荐
- [ ] 课程模块：课程列表、课程详情、课程筛选、材料下载、教学流程
- [ ] 培训模块：培训首页、视频播放、学习进度、必修/选修课程
- [ ] 工具模块：教师工具箱、敏感问题应答、备课助手
- [ ] 用户模块：个人中心、学习记录、收藏、下载、设置

### Web 管理端
- [ ] 数据看板：统计指标、趋势图、主题分布、活跃队伍、待办、动态
- [ ] 课程管理：课程 CRUD、学段/主题/版本管理
- [ ] 培训管理：培训课程管理
- [ ] 案例管理：支教案例管理
- [ ] 种子教师：种子教师认证与管理
- [ ] 支教队伍：队伍信息、服务地区、教师人数
- [ ] 教师管理：教师账号、所属队伍、学习数据
- [ ] 问答与反馈：教师问题与平台反馈
- [ ] 审核中心：课程/案例/资源审核
- [ ] 资源库：教案、课件、教具、视频资源管理
- [ ] 系统设置：账号权限、平台配置
