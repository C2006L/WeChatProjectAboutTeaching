# 接口规范（V1 打样对齐版）

> 通用约定与接口清单。后端由用户自行开发，前端 Mock 优先 + request 封装切换；接口字段结构必须与本规范一致。

## 1. 通用约定
- 协议：HTTP / JSON（UTF-8）
- 基础路径：`/api/...`
- 统一响应结构（后端已建 `Result`）：
```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```
- 分页结构（后端已建 `PageResult`）：
```json
{
  "list": [],
  "total": 0,
  "pageNum": 1,
  "pageSize": 10
}
```
- 错误码来源：后端 `ErrorCode` + `error-code.csv`

## 2. 鉴权约定
- 管理端：JWT（`Authorization: Bearer <token>`）
- 小程序端：微信登录后换取令牌（`Authorization: Bearer <token>`）

### 3.1 关键类型定义

```ts
// 课程摘要
interface CourseSummary {
  id: number;
  title: string;
  theme: string;
  themeLabel: string;
  grade: string;
  duration: number;
  version: string;
  summary: string;
  coverColor: string;
  materials: { plan: number; slides: number; toolkit: number; video: number };
}

// 课程详情
interface CourseDetail extends CourseSummary {
  objectives: string[];
  values: string[];
  sensitiveQa: number[];
  steps: { index: number; title: string; desc: string; duration: number }[];
}

// 培训
interface Training {
  id: number;
  title: string;
  type: 'required' | 'elective';
  duration: number;
  progress: number;
  status: 'done' | 'current' | 'lock';
}

// 培训详情
interface TrainingDetail extends Training {
  videoUrl: string;
  introduction: string;
  outline: string[];
  materials: Material[];
}

// 材料
interface Material {
  id: number;
  type: 'plan' | 'slides' | 'toolkit' | 'video';
  name: string;
  url: string;
  size?: string;
}

// 敏感问题
interface QA {
  id: number;
  question: string;
  category: string;
  scene: string;
  response: string;
  tips: { type: 'do' | 'caution'; content: string }[];
}

// 备课结果
interface PrepareResult {
  grade: string;
  theme: string;
  duration: number;
  recommendedCourses: number[];
  teachingFlow: string[];
  materialChecklist: string[];
  attentionNotes: string[];
}
```

## 5. Mock 切换机制

- 前端 `src/api/` 下每个模块提供 `mockXXX()` 与 `requestXXX()` 两套函数。
- 通过环境变量或统一开关控制：
  - `VITE_USE_MOCK=true`：走 mock 数据
  - `VITE_USE_MOCK=false`：走真实 request
- 默认开发环境启用 mock，后端接口就绪后统一关闭。
- **禁止在页面组件中直接写 mock 数据**，必须通过 api 层调用，保证后端切换时页面零改动。
