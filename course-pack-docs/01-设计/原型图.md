# 原型图（V1 打样对齐版）

> 用结构化文字描述 V1 打样图中各页面布局与区块，供前端开发对照实现。

## 小程序端（course-pack-client）

### P1 首页
- 顶部问候区：
  - 问候语（如“早上好，李老师 🌱”）
  - 副标题（“今天也一起陪伴孩子成长”）
- 支教阶段 Hero 卡：
  - 标题“我的支教阶段”
  - 阶段信息（短期支教 · 第5天）
  - 推荐学段（推荐：小学4-6年级课程）
  - 右侧嫩芽/田园风光插画
- 快速开始（四宫格）：
  - 找课程、学培训、备课工具、问答支持
- 今日推荐：
  - “今天，也许你会用到”
  - 课程卡片（标题、学段、时长、版本、简介、去备课按钮）

### P2 课程列表
- 顶部搜索栏（搜索课程名称）
- 版本切换 Tab：精简版 / 标准版
- 学段筛选：全部 / 1-3年级 / 4-6年级
- 主题筛选：全部 / 家庭 / 身体与安全 / 人际尊重 / 成长
- 课程卡片列表：
  - 左侧主题色块 + 课程名
  - 学段 / 时长 / 版本
  - 一句话简介
  - 右侧主题插画

### P3 课程详情
- 顶部标签（主题标签）
- 标题、学段、时长、版本
- 一句话简介
- 材料图标行：教案 / 课件 / 教具清单 / 课程视频
- Tab 切换：教学流程 / 课程目标 / 价值总结 / 敏感问题
- 教学流程步骤条（StepFlow）
- 底部主按钮：开始备课

### P4 培训首页
- 顶部“我的学习”
- 培训完成度卡片：
  - 进度条 + 百分比（如 75%）
  - 已完成 6 / 8 节
  - 继续学习按钮
- 必修模块：5 节课程列表（带完成状态）
- 选修模块：2 节课程列表（带锁定状态）

### P5 培训视频播放
- 顶部返回 + 课程标题
- 视频播放区（带播放按钮）
- 课程介绍 / 课程大纲 / 资料下载 Tab
- 课程介绍文字
- “你将学到”清单
- 底部：笔记、收藏、下一节按钮

### P6 教师工具箱
- 顶部搜索栏（搜索工具或问题）
- 工具入口列表：
  - 敏感问题应答（蓝色图标）
  - 备课助手（绿色图标）
  - 家校沟通（橙色图标）
  - 课堂活动库（紫色图标）
- 每项含标题、简介、右箭头

### P7 敏感问题应答
- 顶部搜索栏
- 热门问题分类：身体与安全 / 人际关系 / 成长变化
- 问题列表：
  - “老师，男生和女生有什么不一样？”
  - “老师，为什么有人有胸，有人没有？”
  - 等 10 条问题
- 底部“去提问”入口卡片

### P8 备课助手
- 步骤化表单：
  1. 选择年级：1-3年级 / 4-6年级
  2. 选择课程主题：身体与安全 / 家庭与合作 / 人际与尊重 / 成长与变化
  3. 预计授课时间：20分钟 / 30分钟 / 40分钟 / 60分钟
- 底部主按钮：生成备课清单
- 生成后展示：推荐课程、教学流程、材料清单、注意事项

### P9 我的页面
- 用户信息区：
  - 头像、李老师、山东师范大学 × 支教队
  - 种子教师徽章
  - 学习记录入口
- 我的学习：
  - 培训完成度进度条
- 我的内容（四宫格）：
  - 收藏课程、下载记录、我的案例、我的问题
- 我的服务（四宫格）：
  - 微家长信、课堂活动库、反馈建议、帮助中心
- 底部 tabBar

## Web 管理端（course-pack-admin）

### A1 登录
- 居中登录卡片：账号 / 密码
- 品牌标识“伴芽”

### A2 数据看板
- 左侧固定侧边栏：
  - 品牌 Logo + 标语
  - 11 个菜单项
  - 底部品牌卡片“陪伴成长，守护每一颗小芽”
- 顶部欢迎横幅：
  - “欢迎回来，李老师 🌱”
  - 日期
  - 右侧田园风光插画
- 快捷入口：新建课程 / 上传资源 / 发布通知 / 数据导出
- 统计卡片（5 个）：
  - 服务教师总数 356 人
  - 课程学习次数 1,284 次
  - 课程下载次数 863 次
  - 培训完成率 78.6%
  - 覆盖支教队伍 32 支
- 用户增长趋势折线图（近 6 个月）
- 课程使用情况饼图（按主题）
- 近期活跃支教队伍表格
- 右侧边栏：
  - 待办事项（待审核课程 6、待审核案例 12、教师反馈 8、问答待回复 15）
  - 最新动态（课程发布、队伍完成培训、教师注册、课程被收藏）

### A3 课程管理
- 搜索栏 + 主题/学段/状态下拉筛选
- 新增课程按钮
- 课程表格：ID、标题、主题、学段、版本、状态、材料数、操作
- 分页

### A4 ~ A12 占位页
- 培训管理、案例管理、种子教师、支教队伍、教师管理、问答与反馈、审核中心、资源库、系统设置
- 统一使用 EmptyState 组件：图标 + “功能开发中” + 返回数据看板按钮
