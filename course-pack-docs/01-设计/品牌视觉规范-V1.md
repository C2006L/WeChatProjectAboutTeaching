# 伴芽小站品牌视觉规范 V1

## 品牌方向

主题为“田野手记 · 陪伴生长”。视觉应同时传达自然温度与教师工作的专业性：像一本被长期使用的教学手记，而不是儿童卡通应用。

正式品牌图标以项目外部源文件 `D:\panyaimage.png` 为准。图标包含书本、嫩芽、孩子、守护之手、乡村与阳光；产品界面保留完整图标用于品牌识别，页面装饰仅提炼书页、小芽与太阳三种简化符号，不复制复杂渐变。

## 色彩角色

| 角色 | 色值 | 使用范围 |
| --- | --- | --- |
| 品牌主绿 | `#176F66` | 主按钮、导航选中、主视觉卡片、关键数据 |
| 嫩芽绿 | `#A2CBA9` | 生长符号、柔和装饰、低优先级状态 |
| 纸张米白 | `#F6F7F2` | 页面背景 |
| 暖阳橘 | `#F2A06B` | 每屏少量重点、太阳或成长节点 |
| 天空蓝 | `#74B7D3` | 支持类功能与辅助图标 |
| 墨绿黑 | `#253C37` | 标题及主要正文 |

白色仅用于内容卡片和深色底上的主要按钮。暖阳橘不承担大面积背景，天空蓝不与主绿色争夺页面焦点。

## 排版、间距与形状

- 页面大标题 40–48rpx / 600–700；模块标题 32rpx / 600；正文 28rpx / 400；辅助信息不低于 24rpx。
- 以 8rpx 为最小节奏，常用间距为 16、24、32、48rpx。
- 普通卡片圆角 20rpx；重点卡片可使用左上 48–72rpx 的叶片式异形圆角。
- 普通卡片使用低对比描边，不叠加明显灰色阴影；只有重点主卡允许轻柔绿色投影。
- 主按钮高度不低于 72rpx，点击区域不小于 88rpx；线性图标统一使用约 1.8px 视觉线宽。

## 品牌符号规则

- 完整图标：启动、登录、关于、全局品牌标识等需要识别品牌的场景。
- 小芽：学习进度、完成状态、个人成长，仅作数据的视觉注脚，不替代真实数字。
- 打开的书页：课程、备课、首页主卡的底部轮廓。
- 暖阳：一屏最多一个橘色圆形或节点，不重复堆叠。

## 首页组件规则

- 顶部欢迎区保留姓名、支教天数与学段，并用一句短文案建立温度。
- “今日备课”是唯一深色主角卡；长标题最多显示两行，插画固定在右侧且不进入文字安全区。
- 四个常用入口在一个紧凑白色面板中等宽排列，通过浅绿、浅蓝、浅橘区分功能，不增加解释性小字。
- 培训进度与最近备课均采用信息优先的白色卡片；列表行保持足够点击高度和清晰分隔。
- 320–430px 视口下不出现横向滚动、标题遮挡、胶囊冲突或底部导航覆盖。
